# Instagram Full-Stack Social Media Application

A full-stack social media application inspired by Instagram, built using React.js, Node.js, Express.js, MongoDB and Socket.IO.

## 🚀 Live Demo

https://instagram-fullstack-nine.vercel.app

## 📂 GitHub Repository

https://github.com/vijaylaxmi88582-art/instagram-fullstack

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- Axios
- React Router
- CSS
- Vite

### Backend
- Node.js
- Express.js
- REST API
- JWT Authentication
- Socket.IO

### Database
- MongoDB
- Mongoose

### Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas

## ✨ Features

- User Signup and Login
- JWT-based Authentication
- User Profiles
- Create and View Posts
- Like Posts
- Comment on Posts
- Follow and Unfollow Users
- Stories
- User Feed
- Profile Pages
- Real-time communication using Socket.IO
- Responsive UI
- RESTful APIs
